🎼 Fabula Ultima — Chanter Composer
Create songs for the Chanter class directly in Foundry VTT. The composer brings learned notes, song previews, and a personal repertoire together in one panel.

This is an independent, unofficial module by DM Arkhron for use with ProjectFU. Fabula Ultima and ProjectFU belong to their respective creators.
✨ Why use it?
Combine a Volume, Key, and Tone to compose a verse. Review its targets, MP cost, and effect before singing, then save your favorite combinations for later.
🎯 Features
- 🎵 Visual composer — Build verses from the character’s available notes.
- 📖 Learned notes — Mark new Keys and Tones as the character progresses.
- 🔮 Song preview — Check targets, MP cost, and effect before posting to chat.
- 📚 Personal repertoire — Save songs with an optional name and description, read their details, and load them again.
- 💬 Interactive chat cards — Announce a song and use its buttons to spend MP and apply available effects to selected targets.
- 🎨 ProjectFU-inspired appearance — A green and light-colored interface using the system’s elemental icons.
- 🎼 Ready-to-use macro — Drag the macro from Chanter Composer | Macros to the hotbar.
- 🌐 English and Portuguese — English is the initial default; Portuguese can be selected in the module settings.
⚙️ Compatibility
Requirement	Version
Foundry VTT	V13
Game system	ProjectFU
Chanter Composer	1.0.0


The module requires a world running ProjectFU. V14 compatibility has not been declared for this release.
📦 Installation
In Foundry, open Add-on Modules → Install Module and paste this URL into Manifest URL:
https://raw.githubusercontent.com/DMArkhron/fabula-ultima-chanter-composer-dm-arkhron/main/module.json

Enable the module in your world. For manual installation, download the v1.0.0 release ZIP and extract the fabula-ultima-chanter-composer-dm-arkhron folder into Data/modules/.
Manifest installation will work once module.json is available in the repository and the matching ZIP has been attached to the v1.0.0 release.

🎮 Getting started
1. Open the composer from the Card Decks sidebar tab, or drag its compendium macro to the hotbar.
2. Select your character’s token or assign a character to your Foundry user.
3. Mark learned notes and combine Volume + Key + Tone.
4. Review the preview, save the song to your repertoire, or sing it.
5. Select the targets and use the chat card’s cost and effect buttons as needed.
