# 🎼 Fabula Ultima — Chanter Composer

Compose songs for the **Chanter** class directly in Foundry VTT. Manage learned notes, preview each verse, and keep your character’s songs in a personal repertoire.

This is an **independent, unofficial module** created by **DM Arkhron** for **ProjectFU**. Fabula Ultima and ProjectFU belong to their respective creators.

## ✨ Why use it?

Combine a **Volume**, **Key**, and **Tone** to create a verse. See its targets, MP cost, and effect before singing, then save your favorite songs for future sessions.

## 🎯 Features

- 🎵 **Visual composer:** Create verses from the character’s available notes.
- 📖 **Learned notes:** Track new Keys and Tones as the character progresses.
- 🔮 **Verse preview:** Review targets, MP cost, and effects before posting to chat.
- 📚 **Personal repertoire:** Save songs with an optional name and description, read their details, and load them again.
- 💬 **Interactive chat cards:** Spend MP and apply available effects to selected targets using buttons on the card.
- 🎨 **ProjectFU-inspired design:** Green and light-colored panels with the system’s elemental icons.
- 🎼 **Ready-to-use macro:** Drag the macro from the **Chanter Composer | Macros** compendium to your hotbar.
- 🌐 **English and Portuguese:** English is selected by default; Portuguese is available in the module settings.

## ⚙️ Compatibility

| Requirement | Version |
| --- | --- |
| Foundry VTT | V13 |
| Game system | ProjectFU |
| Chanter Composer | **1.0.0** |

The module requires a world running **ProjectFU**. V14 compatibility has not been declared for this release.

## 📦 Installation

In Foundry, open **Add-on Modules → Install Module** and paste this URL into **Manifest URL**:

```text
https://raw.githubusercontent.com/DMArkhron/fabula-ultima-chanter-composer-dm-arkhron/main/module.json
```

Enable **Fabula Ultima - Chanter Composer - DM Arkhron** in your world.

For manual installation, download the ZIP attached to the `v1.0.0` release and extract the `fabula-ultima-chanter-composer-dm-arkhron` folder into `Data/modules/`.

## 🎮 Getting started

1. Open the composer from the **Card Decks** sidebar tab, or drag its compendium macro to your hotbar.
2. Select your character’s token or assign a character to your Foundry user.
3. Mark learned notes and combine **Volume + Key + Tone**.
4. Review the verse, save it to your repertoire, or sing it.
5. Select the targets and use the chat card’s buttons to apply costs and effects.
