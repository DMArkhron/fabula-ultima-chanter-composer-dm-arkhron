# Fabula Ultima - Chanter Composer - DM Arkhron

Módulo para Foundry VTT v13 com o sistema [ProjectFU](https://github.com/League-of-Fabulous-Developers/FoundryVTT-Fabula-Ultima). Versão **1.0.0**.

## Instalação

No Foundry, abra **Add-on Modules → Install Module**, cole o endereço abaixo em **Manifest URL** e instale:

```text
https://raw.githubusercontent.com/DMArkhron/fabula-ultima-chanter-composer-dm-arkhron/main/module.json
```

Ative o módulo no mundo que usa ProjectFU. Como alternativa, baixe o ZIP da release e extraia a pasta `fabula-ultima-chanter-composer-dm-arkhron` em `Data/modules/`.

## Uso

Abra o compositor pela aba **Baralhos** ou pelo compêndio **Chanter Composer | Macros**. Arraste **Open Chanter Composer / Abrir Compositor** à barra de macros. Selecione um token de personagem ou atribua um personagem ao usuário. O idioma inicial é inglês; é possível escolher português nas configurações do módulo.

Marque as tonalidades e os tons aprendidos, monte versos, salve canções no repertório e anuncie seus efeitos no chat. Os cards oferecem ações para o custo em PM e os efeitos sobre os alvos selecionados. A disponibilidade das opções e as canções são armazenadas na ficha do personagem.

## Publicação da versão 1.0.0

O manifesto usa os links deste repositório e aponta para o asset da release chamado `fabula-ultima-chanter-composer-dm-arkhron-v1.0.0.zip`. O ZIP precisa conter a pasta `fabula-ultima-chanter-composer-dm-arkhron` na raiz. Use a tag `v1.0.0`.
